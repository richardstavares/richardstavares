## 👋 Sobre

Trabalho com TI na ponta — infraestrutura, redes e suporte — e nos últimos anos venho levando
esse trabalho para o código: cada processo repetitivo vira script, container ou aplicação.

Hoje divido o tempo entre manter ambientes rodando e construir interfaces em **Next.js**,
normalmente resolvendo dores reais de operação: atendimento, helpdesk, e-commerce e
ferramentas internas.

- 🔭 Construindo aplicações web com **Next.js + shadcn/ui + TypeScript**
- 🛠️ Automatizando rotinas de infra com **PowerShell**, **Python** e **Docker**
- 🌱 Estudando cloud, IA aplicada e boas práticas de segurança
- 💬 Aberto a conversar sobre automação, infra e projetos web
